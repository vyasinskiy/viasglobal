# Персональный автономный AI-ассистент (Hermes Agent)

Автономный сервис личного ассистента владельца бизнеса на базе платформы **Hermes Agent** (Nous Research). Работает в изолированном Docker-контейнере, принимает команды через личного Telegram-бота и взаимодействует с микросервисами монорепозитория по HTTP.

## Возможности

1. **Единый персональный ассистент**:
   - Работает через выделенного Telegram-бота только для владельца (`TELEGRAM_ALLOWED_USERS=743866013`).
   - Поддерживает диалоги, запоминает контекст и предпочтения (долговременная память SQLite + FTS5).
   - Принимает голосовые заметки, текстовые команды и фотографии.

2. **Интеграция с сервисом аренды (`rent / accountant`)**:
   - Получение списка жильцов и привязанных квартир (`rent_get_tenants`).
   - Просмотр последних начислений и квитанций ЖКУ (`rent_get_invoices`).
   - Подготовка и регистрация платежей (`rent_create_payment`).

3. **Интеграция с оптовой торговлей (`backend / core`)**:
   - Поиск брендов, проверка статусов и заметок (`wholesale_get_brands`).
   - Просмотр информации о дистрибьюторах (`wholesale_get_distributors`).

4. **Модель и провайдер**:
   - OpenRouter API с моделью **DeepSeek-V3** (`deepseek/deepseek-chat`).

## Структура подпроекта

```text
viasglobal/hermes/
├── .agents/
│   └── AGENTS.md        # Правила для ИИ ассистента
├── README.md            # Данный документ
├── Makefile             # Команды управления контейнером (make deploy, make logs)
├── deploy.sh            # Скрипт развертывания с автопроверкой сетей
├── Dockerfile           # Сборка контейнера на базе Python 3.11-slim
├── docker-compose.yml   # Развертывание контейнера Hermes Agent
├── requirements.txt     # Python зависимости (python-telegram-bot, openai, faster-whisper)
├── .env.example         # Шаблон переменных окружения
├── .env                 # Конфигурация с API-ключами (не коммитится)
├── src/                 # Исходный код агента
│   ├── main.py          # Точка входа, Telegram бот (polling), авторизация, встроенный Whisper
│   ├── agent.py         # Ядро агента Hermes, интеграция OpenRouter, Tool Calling
│   ├── tools_loader.py  # Динамический загрузчик инструментов и генератор схем
│   └── database.py      # Долговременная память на SQLite
├── config/
│   ├── config.yaml      # Конфигурация платформы Hermes и регистрация Tools
│   └── prompt.txt       # Системная персона и финансовые правила
├── tools/               # Пользовательские инструменты HTTP-вызовов
│   ├── rent_tools.py    # Инструменты для работы с арендой (accountant)
│   └── backend_tools.py # Инструменты для оптовой торговли (backend)
└── data/                # Смонтированный том для долговременной памяти SQLite (agent.db)
```

## Развертывание

### 1. Локально / в корне проекта
Синхронизация и развертывание на сервере Huawei одной командой из корня репозитория:
```bash
make deploy-hermes
```

### 2. Прямо на сервере
```bash
cd ~/viasglobal/hermes
make deploy
```
