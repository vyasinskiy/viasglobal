# Viasglobal Store — Интернет-магазин (España / EU)

Официальный онлайн-магазин премиальной электроники, устройств для умного дома и аксессуаров для эргономичного рабочего места в Испании и странах Европейского Союза.

Интерфейс витрины выполнен на **испанском языке (основной)** с поддержкой **английского языка** через переключатель `[ 🇪🇸 ES | 🇬🇧 EN ]` в шапке сайта.

## Стек технологий
- **Next.js 16 (App Router)** + **React 19**
- **TypeScript** для строгой типизации
- **Zustand** с сохранением корзины, списка желаний и выбранного языка в `localStorage`
- **Vanilla CSS** + Glassmorphism дизайн-система
- **Lucide Icons**
- **Мультиязычность**: Испанский (`es`, по умолчанию) + Английский (`en`)

## Быстрый старт

### Установка зависимостей
В директории `shop`:
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу: [http://localhost:3001](http://localhost:3001).

### Сборка проекта
```bash
npm run build
npm run start
```

## Функционал интернет-магазина
1. **Переключение языков (`ES` / `EN`)**:
   - Мгновенное переключение языка всех страниц, каталога, характеристик товаров, корзины и оформления заказа в реальном времени.
2. **Главная витрина (`/`)**:
   - Hero-баннер с флагманским продуктом и акцентами.
   - Сетка популярных направлений и промо-баннер со скидкой 10% (код `VIAS10`).
   - Блоки хитов продаж и рекомендуемых новинок.
   - Европейские преимущества (склад в Испании, доставка за 24-48ч, 2 года гарантии).
3. **Каталог товаров (`/products`)**:
   - Фильтрация по категориям (Аудио, Рабочее место, Умный дом, Зарядки GaN, Лайфстайл).
   - Поиск по названию, бренду и описанию в реальном времени.
   - Сортировка по цене и рейтингу.
   - Фильтр «Только в наличии» и просмотр списка «Избранное».
4. **Карточка товара (`/products/[id]`)**:
   - Галерея фотографий высокого разрешения.
   - Подробная таблица характеристик и преимуществ.
   - Отзывы покупателей с рейтингом.
   - Блок связанных товаров.
5. **Корзина и Drawer (`/cart` и Slide-over)**:
   - Автоматический подсчет бесплатной доставки от €50.
   - Применение промокодов (например, `VIAS10`).
   - Расчет НДС 21% (IVA).
6. **Оформление заказа (`/checkout`)**:
   - Выбор страны ЕС и адреса доставки.
   - Поддержка реквизитов компаний (VIES 0% VAT).
   - Выбор способов доставки (Correos / SEUR / DHL Express).
   - Способы оплаты (Банковские карты, Apple Pay, PayPal, Klarna).
   - Чекбокс согласия с RGPD и Aviso Legal.
7. **Подтверждение заказа (`/checkout/success`)**:
   - Салют конфетти, номер заказа, таймлайн статуса доставки и печать чека.
8. **Информационные страницы**:
   - О компании (`/about`)
   - Доставка и гарантия (`/shipping`)
   - Контакты и поддержка (`/contact`)
   - Правовая информация LSSICE (`/legal`)
   - Политика конфиденциальности RGPD (`/privacy`)

└── tsconfig.json
