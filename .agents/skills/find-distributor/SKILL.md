# Инструкция для ИИ

## Задача
Пользователь передает файл или список товаров из директории `keepa/`.
Твоя цель — найти контакты официальных европейских B2B дистрибьюторов (wholesale) для указанных брендов/товаров.

## Алгоритм работы
1. **Извлечение данных**: Если передан Excel/CSV файл из папки `keepa/`, **НЕ пытаться** читать его напрямую. Запусти вспомогательный Python-скрипт из этого скилла:
   `python .agents/skills/find-distributor/scripts/extract.py <путь_к_файлу>`
   Этот скрипт сам найдет колонки Manufacturer (DR) и Brand (DS) и выдаст тебе короткий список уникальных брендов.
2. **Поиск дистрибьюторов**:
   - Используй инструмент веб-поиска по специализированным B2B-запросам (например: `"[Бренд] official wholesale distributor Europe"`, `"[Бренд] B2B contact form"`).
   - При необходимости используй браузерный агент (browser subagent) для навигации по сайтам и поиска страниц контактов.
3. **Отчетность**: Сохрани результаты в виде Markdown-таблицы (Бренд, Сайт дистрибьютора, Контакты) и создай артефакт с отчетом.

## Ограничения
- Искать только B2B контакты (не розничные магазины).
- Приоритет — дистрибьюторы в Евросоюзе, работающие с Amazon FBA.
