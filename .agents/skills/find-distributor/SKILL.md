# Инструкция для ИИ

## Задача
Пользователь передает файл или список товаров из директории `keepa/`.
Твоя цель — найти контакты официальных европейских B2B дистрибьюторов (wholesale) для указанных брендов/товаров.

## Алгоритм работы
1. **Подготовка и парсинг ASIN**:
   - Используй первый скрипт для извлечения уникальных брендов и производителей из выгрузки Keepa:
     `npx tsx .agents/skills/find-distributor/scripts/extract/extract.ts <путь_к_файлу>`
   - После того, как выберешь бренды для анализа, для каждого из них запусти второй скрипт, чтобы получить чистый список ASIN:
     `npx tsx .agents/skills/find-distributor/scripts/extract-asins/extract-asins.ts <путь_к_файлу> "Название бренда"`
2. **Поиск дистрибьюторов**:
   - Найди в интернете контакты официальных европейских дистрибьюторов и ссылки на их B2B порталы или формы регистрации.
3. **Отчетность**: Сохрани результаты в виде Markdown-таблицы со следующими колонками и создай артефакт с отчетом:
   - **Бренд**
   - **Сайт бренда**
   - **Ссылка на страницу со списком дистрибьюторов** (ссылка на то место на сайте производителя, где найден список официальных дистрибьюторов)
   - **Контакты дистрибьютера** (email, телефон, адрес)
   - **Ссылка на форму регистрации** (прямая ссылка на форму регистрации B2B-клиента на сайте дистрибьютора, если таковая имеется, либо пометка об ее отсутствии)
   - **Обоснование** (почему ты решил, что это официальный дистрибьютор)
   - **Описание** (краткая справка о дистрибьюторе или условиях работы. **ВАЖНО:** каждый приведенный факт, например, минимальный заказ (MOQ) или условия доставки, должен обязательно сопровождаться ссылкой на страницу-источник для проверки)
   - **Список ASIN** (Только ASIN, привязанные к этому бренду, которые выдал скрипт, без названий товаров. ВАЖНО: форматируй каждый элемент с новой строки внутри ячейки таблицы, используя тег `<br>`)

   > **ВАЖНО:** Перед формированием отчета обязательно прочитай файл `.agents/skills/find-distributor/examples/good-report.md`, чтобы понять идеальный формат и тон (Tone of Voice). Твой результат должен быть структурно идентичен этому эталону без лишней "воды".

## Ограничения
- Искать только B2B контакты (не розничные магазины).
- Приоритет — дистрибьюторы в Евросоюзе.
