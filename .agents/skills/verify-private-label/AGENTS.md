# Инструкции для ИИ (verify-private-label)

- **Назначение**: Проверка связки Бренд + Продавец на статус Private Label по данным базы данных.
- **Скрипт**: `backend/scripts/verify-private-label.ts`.
- **Запуск**:
  ```bash
  cd backend && npx tsx scripts/verify-private-label.ts "<brandName>" "<sellerId_or_sellerName>"
  ```
- **Правила анализа цен и продавцов**:
  - Сравнивать текущую цену товара со **средней ценой этого же конкретного товара за 90 дней (`buyBox90DaysAvg`)** и рекомендованной розничной ценой (`listPriceCurrent`). Не усреднять цены разных товаров по каталогу.
  - Делать корректный вывод для оптовой стратегии (Wholesale): сторонним продавцам эти единичные позиции могут быть выгодны в рамках их штучной модели, но для нас бренд не подходит для оптовых закупок из-за монополизации 90–99% каталога и отсутствия дистрибуции.
- **Правило перехода к добавлению**: При подтверждении статуса Private Label (и отсутствии записи в `PrivateLabel`) обязательно спросить у пользователя подтверждение на внесение в базу данных, и при согласии активировать навык `add-private-label`.
