# Документация навыка verify-private-label

Навык **`verify-private-label`** предназначен для программной проверки гипотезы о том, торгует ли продавец товарами бренда по модели **Private Label** (является владельцем бренда или его монопольным/эксклюзивным дистрибьютором) или это классическая оптовая модель (**Wholesale**).

## Как работает навык

1. **Проверка в БД (Таблица PrivateLabel)**:
   - Проверяется, была ли данная связка уже зафиксирована в базе ранее.

2. **Текстовое совпадение (Бренд / Производитель vs Продавец)**:
   - Если имя продавца содержит название бренда, связка сразу считается Private Label (`BUYBOX_MATCH_BRAND`).

3. **Количественный анализ листингов в БД**:
   - Находятся все товары бренда (`ASIN` + `ProductFinder`).
   - Считается доля листингов с 1 продавцом (`newOfferCountCurrent = 1`). Порог подтверждения: **> 50%**.
   - Считается процент удержания BuyBox целевым продавцом. Порог подтверждения: **> 90%**.

4. **Дальнейшие сценарии**:
   * **При подтверждении Private Label**: предлагает зафиксировать связку в БД через навык `add-private-label`.
   * **При подтверждении Wholesale**: сообщает, что бренд открыт для оптовой закупки, и предлагает найти официальных европейских B2B дистрибьюторов через навык `find-distributor`.

## Использование

### Через ИИ в чате
- *"Проверь связку Jerry Fabrics и Theonoi"*
- *"Проверь приватный лейбл Poligino SUNRICE MERCANTILE"*

### Вручную из терминала
```bash
cd backend && npx tsx scripts/verify-private-label.ts "Jerry Fabrics" "Theonoi"
```
или по Seller ID:
```bash
cd backend && npx tsx scripts/verify-private-label.ts "Jerry Fabrics" "A1V55SZ7ZUXV26"
```
