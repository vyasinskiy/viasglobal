# Установка и запуск (Только для AI)

Этот навык активируется ТОЛЬКО когда пользователь явно просит **запросить свежие данные по API**, **скачать данные из Keepa** или **принудительно обновить/стянуть данные по ASIN через API** (например: "запроси этот асин по апи", "скачай свежие данные keepa для B012345678", "сделай api запрос для асина").
Не путай с обычной просьбой "покажи данные" (в таком случае данные нужно просто искать в БД, например в `ProductFinder` или `KeepaApiProcessedData`).

## Описание

Скрипт добавляет ASIN в очередь `WholesaleAsinQueue` с максимальным приоритетом (999999), затем принудительно вызывает методы NestJS `fetchRawData` и `processRawData`, чтобы мгновенно прогнать товар по всем трем таблицам и вывести финальный результат из чистовика.

## Инструкция по выполнению

1. Извлеки ASIN из запроса пользователя.
2. Перейди в папку `backend` и выполни команду:
   ```bash
   npx tsx scripts/fetch-keepa-asin.ts <ASIN>
   ```
3. Проанализируй вывод скрипта в консоли. 
4. Сообщи пользователю успешный результат (габариты, Size Tier и другие полученные метрики).
