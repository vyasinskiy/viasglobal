# Навык: Cofan Adapter (Адаптер поставщика Cofan)

Этот навык предназначен для взаимодействия с испанским дистрибьютором и производителем **Cofan La Mancha S.A.** (`cofan.es`).
Он автоматизирует процесс получения оптовых цен, расчет себестоимости и безопасный импорт в базу данных.

---

## 🔒 Ключевое правило безопасности данных (Анти-слепые изменения)

Импорт цен в базу данных выполняется строго в два шага:
1. **Формирование промежуточной таблицы во временном Excel** (`staging_prices.xlsx`) для визуального контроля пользователем.
2. **Обязательное получение явного согласия пользователя** перед выполнением любых операций записи в БД (`DistributorPriceSnapshot`, связывание ASIN).

---

## 📋 Пошаговый алгоритм работы

### Шаг 1. Проверка сессии веб-портала Cofan
- Сессия хранится в `contractors/COFAN/auth/storage_state.json`.
- Если файл отсутствует или сессия устарела, пользователь запускает скрипт интерактивного входа:
  ```bash
  cd ecommerce/backend && npx tsx ../../.agents/skills/cofan-adapter/scripts/save-session.ts
  ```

### Шаг 2. Сбор оптовых цен по EAN (`fetch-cofan-prices.ts`)
- Адаптер принимает список EAN / ASIN либо файл выгрузки Keepa.
- Для каждого EAN выполняется точечный поиск на `https://www.cofan.es/es/buscar/?name=<EAN>`.
- Из таблицы `#tablaReferencia` извлекаются:
  - Внутренний артикул Cofan (`referencia`).
  - Оптовая чистая цена (`priceNetto`).
  - Каталожная розничная цена (`PVP`).
  - Фабричная упаковка / количество единиц в одной коробке (`EMBALAJE` -> `unitsPerBox`).
  - Минимальный заказ в коробках (`ENVASE MÍNIMO` -> `minBoxEnvases`, в БД `minBoxOrder = unitsPerBox * minBoxEnvases`).
  - Статус наличия на складе (`stock`).
- Вычисляется себестоимость закупки с учетом режима *Recargo de Equivalencia* в Испании:
  $$\text{costPrice} = \text{priceNetto} \times 1.262 \quad (21\% \text{ IVA} + 5.2\% \text{ R.E.})$$

### Шаг 3. Создание промежуточного Excel файла для ручной проверки
- Формируется файл: `contractors/COFAN/reports/cofan_staging_prices_<timestamp>.xlsx`.
- Таблица содержит колонки:
  `EAN`, `ASIN`, `Артикул Cofan`, `Наименование`, `BSR`, `Закупка Neto (€)`, `Себестоимость с R.E. (€)`, `Каталожный PVP (€)`, `Штук в коробке (Embalaje)`, `Мин. заказ коробок (Envase)`, `Amazon BuyBox (€)`, `Наличие на складе`.
- Пользователю предоставляется прямая ссылка на файл и краткая сводка (количество распознанных позиций, средний ROI).

### Шаг 4. Согласование и подтверждение с пользователем
- ИИ задает пользователю вопрос:
  > *«Промежуточный файл с ценами сформирован: [ссылка]. Вы подтверждаете загрузку этих цен в базу данных?»*
- **Без явного подтверждения («Да», «Подтверждаю», «Загружай») операция записи НЕ выполняется!**

### Шаг 5. Импорт подтвержденных цен в базу данных (`import-cofan-to-db.ts`)
- Запуск выполняется командой:
  ```bash
  cd ecommerce/backend && npx tsx ../../.agents/skills/cofan-adapter/scripts/import-cofan-to-db.ts <путь_к_staging_файлу.xlsx>
  ```
- Скрипт:
  1. Находит дистрибьютора `Cofan` в таблице `Distributor` (ID: 6) и выставляет статус `ACCOUNT_OPENED`.
  2. Создает снапшоты в таблице `DistributorPriceSnapshot` (`priceNetto`, `costPrice`, `unitsPerBox`, `minBoxOrder`).
  3. Связывает найденные `ASIN` с дистрибьютором Cofan (`_ASINToDistributor`).
  4. Добавляет товары в очередь `RequestProductQueue` с наивысшим приоритетом (`999999`) для обновления Keepa.
  5. Переводит статус бренда `COFAN` в `'CONTRACTED'` (при необходимости), чтобы товары отображались в представлении `ContractedAllProductsView`.

### Шаг 6. Обязательная очистка временных и промежуточных файлов
- **Правило гигиены репозитория**: сразу после успешного импорта в базу данных ИИ **обязан удалить все временные файлы**:
  - Временный staging Excel (`cofan_staging_prices_*.xlsx`).
  - Промежуточные JSON-файлы и черновики отчетов (`reports/*`).
  - Временные тестовые скрипты.
- Вся актуальная информация сохраняется в базе данных (в таблице `DistributorPriceSnapshot` и представлении `ContractedAllProductsView`), а постоянные правила — в `README.md` и `AGENTS.md`. В репозитории не должно оставаться промежуточного мусора.
