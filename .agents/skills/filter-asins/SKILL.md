# Инструкция для ИИ

## Триггер активации
Этот навык должен активироваться, когда пользователь произносит фразу "отфильтруй асины" (или аналогичную по смыслу, указывая путь к файлу Keepa Export).

## Задача
Пользователь передает файл или список товаров из директории `keepa/`.
Твоя цель — проанализировать эту выгрузку, отфильтровать бренды/производителей (отбросить те, где Amazon или сам бренд является продавцом), а также проверить их статус в нашей БД (отбросить приватные лейблы). В результате сформировать чистый Excel файл с 5 колонками.

## Алгоритм работы
1. **Первичная очистка и фильтрация (Amazon/Brand sellers)**:
   - Запусти скрипт `filter-safe-asins.ts`, передав ему путь к исходному файлу Excel:
     `npx tsx .agents/skills/filter-asins/scripts/filter-safe-asins/filter-safe-asins.ts <путь_к_исходному_файлу>`
   - Этот скрипт удалит лишние колонки (оставит 5) и отфильтрует товары, которые продаются самим Amazon или брендом. Результат сохранится в директорию `keepa/results/` с суффиксом `_SAFE.xlsx`.

2. **Проверка в БД на приватные лейблы**:
   - Затем запусти второй скрипт `filter-db.ts`, передав ему путь к только что созданному `_SAFE.xlsx` файлу:
     `npx tsx .agents/skills/filter-asins/scripts/filter-db.ts <путь_к_созданному_SAFE_файлу>`
   - Скрипт сделает запросы к бэкенду (http://localhost:3001) и отсеет товары брендов, отмеченных как приватный лейбл.
   - Финальный результат будет сохранен в `keepa/results/` с суффиксом `_SAFE-Filtered.xlsx`.

3. **Очистка**:
   - Удали промежуточный файл `_SAFE.xlsx` из `keepa/results/`, чтобы не засорять директорию:
     `rm <путь_к_SAFE_файлу>`

4. **Результат**:
   - Предоставь пользователю сводку по отфильтрованным позициям, укажи сколько было и сколько осталось.
   - Обязательно дай кликабельную markdown-ссылку на финальный файл `_SAFE-Filtered.xlsx`.
