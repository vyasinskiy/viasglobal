# Документация подпроекта: Фильтрация ASIN-ов

Этот подпроект отвечает за анализ и фильтрацию ASIN-ов (идентификаторов товаров Amazon) на основе данных о владельцах BuyBox. Основная цель — выявлять скрытые Private Label (когда один продавец монополизирует бренд).

## Логика "Доминирующего продавца"

Для выявления ситуаций, когда продавец является эксклюзивным представителем (или это скрытый Private Label), применяется двухэтапная проверка в функции базы данных `get_asin_filter_reason(p_asin_id INT, p_dominant_threshold INT)`. По умолчанию порог `p_dominant_threshold` равен 80 (80%).

### Этап 1: Проверка текущего ASIN
1. **Извлечение процента владения:** Из строки с продавцом (например, `Pulchlla (100%) / API5SQCLMSM0Q`) извлекается процент владения BuyBox для данного ASIN (в данном случае — 100).
2. **Оценка доминирования на товаре:** 
   - Если этот процент **меньше** `p_dominant_threshold` (80%), то продавец не доминирует даже на этом конкретном товаре. Проверка доминирования прерывается, и функция переходит к стандартным проверкам (совпадение имени бренда и т.д.).
   - Если процент **больше или равен** `p_dominant_threshold`, продавец доминирует на текущем ASIN. Алгоритм переходит ко второму этапу.

### Этап 2: Проверка связки Бренд + Производитель
Если продавец доминирует на текущем товаре, мы проверяем, не монополизировал ли он **всю связку** этого Бренда и Производителя:
1. **Подсчет общего числа:** Считается общее количество ASIN-ов у данной связки Бренд + Производитель.
2. **Подсчет числа ASIN-ов продавца:** Считается, для скольких из этих ASIN-ов этот же продавец (по его уникальному ID `API5SQCLMSM0Q`) является победителем BuyBox.
3. **Вычисление доли:** Вычисляется доля: `(количество_асинов_этого_продавца / общее_количество_асинов) * 100`.
4. **Принятие решения:**
   - Если эта доля **больше или равна** `p_dominant_threshold` (например, продавец держит 12 из 14 ASIN-ов связки, что равно ~85%), функция возвращает причину `DOMINANT_SELLER` (ASIN отфильтровывается).
   - Если доля **меньше** `p_dominant_threshold` (например, 4 из 14 = 28%), ASIN **НЕ** отфильтровывается как доминирующий.
   - *Примечание:* Если у связки Бренд+Производитель существует всего 1 ASIN, то доля составит 1/1 = 100%. В этом случае ASIN будет успешно отфильтрован как `DOMINANT_SELLER`, так как продавец забирает 100% "всего бренда".
