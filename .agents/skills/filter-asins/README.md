# Документация подпроекта: Фильтрация ASIN-ов

Этот подпроект отвечает за анализ и фильтрацию ASIN-ов (идентификаторов товаров Amazon) на основе данных о владельцах BuyBox. Основная цель — выявлять скрытые Private Label и монополизированные листинги, оставляя только листинги с конкуренцией для оптовой продажи (Wholesale).

## Критерии выборки и фильтрации

Товары оцениваются функцией базы данных `get_asin_filter_reason(p_asin_id INT, p_dominant_threshold INT DEFAULT 90, p_min_winner_count INT DEFAULT 4)`.

### 1. Критерий количества продавцов (от 4 продавцов)
- **Метрика:** `buyBoxWinnerCount90Days` (количество уникальных продавцов, выигрывавших Buy Box за последние 90 дней).
- **Правило:** Если `buyBoxWinnerCount90Days < 4` (т.е. 1, 2 или 3 продавца), листинг признается недостаточно конкурентным/монопольным и отсеивается с причиной **`FEW_BUYBOX_WINNERS`** (критерий прохождения: строго от 4 продавцов).

### 2. Критерий доминирования топового продавца (доля < 90%)
- **Метрика:** `buyBoxTopSeller90Days` (доля времени за последние 90 дней, в течение которого лидирующий продавец удерживал Buy Box; в базе данных хранится как десятичная дробь от `0.0` до `1.0`, например `0.90` = 90%).
- **Правило:** Если `buyBoxTopSeller90Days >= 0.90` (90%), один игрок забирает практически все продажи, и ASIN отсеивается с причиной **`DOMINANT_BUY_BOX_SELLER`**. Функция `get_asin_filter_reason` автоматически переводит переданный целый процент (например, `90`) в коэффициент `0.90`.

### 3. Критерий доминирования продавца в каталоге бренда (Macro Dominance >= 80%)
- **Метрика:** Доля всех товаров бренда в базе данных, где целевой продавец удерживает Buy Box (проверка функцией `check_brand_seller_dominance(p_brand_id, p_seller_id, 80)` при наличии двух выгрузок Keepa: каталога бренда и витрины продавца).
- **Правило:** Если целевой продавец удерживает `>= 80%` каталога бренда, весь бренд у этого продавца признается монополизированным, и ASIN отсеивается с причиной **`DOMINANT_BRAND_SELLER`**. Это предотвращает просачивание монополистов на отдельных остаточных листингах с ложной конкуренцией.

### 4. Текстовые и структурные проверки
- **`NO_BUYBOX_DATA`**: отсутствие данных о BuyBox.
- **`BUYBOX_MATCH_BRAND`**: совпадение имени продавца с брендом.
- **`BUYBOX_MATCH_MANUFACTURER`**: совпадение имени продавца с производителем.
- **`PRIVATE_LABEL`**: подтвержденная связка Бренд + Продавец в таблице `PrivateLabel`.

Если ни один фильтр не сработал (возвращается `NULL`), товар считается чистым и пригодным для оптовой работы.
