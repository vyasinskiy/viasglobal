# Инструкция по безопасному поиску (Verified Search)

Этот скилл предназначен для поиска информации в интернете с гарантией того, что найденные URL-адреса действительно существуют и доступны, а не выдуманы языковой моделью.

## Алгоритм работы

1. **Поиск информации**:
   - Используй инструмент веб-поиска (`search_web`) с нужным запросом.
   - Изучи результаты (summary).
2. **Обязательная проверка ссылок (Анти-галлюцинация)**:
   - Инструменты веб-поиска иногда могут выдумывать (галлюцинировать) URL-адреса.
   - Сразу после нахождения потенциальной ссылки в выдаче, ты **ОБЯЗАН** проверить её работоспособность с помощью скрипта-хелпера:
     `npx tsx .agents/skills/verified-search/scripts/checkIfNot404.ts <url>`
   - Если скрипт вернул HARD_ERROR (код выхода 1), значит ссылка точно нерабочая. **Запрещено** её использовать.
   - Если скрипт выявил признаки пустой страницы/ошибки (SOFT_404_DETECTED, код выхода 2), ты **ОБЯЗАН** запустить инструмент `browser_subagent` для визуальной проверки этой ссылки, так как это может быть просто заглушка (Soft 404) или защита от ботов. Если субагент подтвердит, что страница пустая/ошибка, использовать ссылку запрещено.
   - Если скрипт вернул PAGE_LOOKS_OK (код выхода 0), ссылку можно считать рабочей.
   - При нерабочей ссылке продолжай поиск и ищи альтернативы.
3. **Результат**:
   - Возвращай пользователю (или вызывающему скиллу) только ту информацию и ссылки, которые успешно прошли проверку скриптом `checkIfNot404.ts` (или подтверждены через `browser_subagent`).
