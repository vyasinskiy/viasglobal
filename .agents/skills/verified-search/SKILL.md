# Инструкция по безопасному поиску (Verified Search)

Этот скилл предназначен для поиска информации в интернете с гарантией того, что найденные URL-адреса действительно существуют и доступны, а не выдуманы языковой моделью.

## Алгоритм работы

1. **Поиск информации**:
   - Используй инструмент веб-поиска (`search_web`) с нужным запросом.
   - Изучи результаты (summary).
2. **Обязательная проверка ссылок (Анти-галлюцинация)**:
   - Инструменты веб-поиска иногда могут выдумывать (галлюцинировать) URL-адреса.
   - Сразу после нахождения потенциальной ссылки в выдаче, ты **ОБЯЗАН** проверить её работоспособность с помощью скрипта-хелпера:
     `npx tsx .agents/skills/verified-search/scripts/curl.ts <url>`
   - Если скрипт вернул ошибку (статус не 2xx/3xx), значит ссылка нерабочая или выдуманная. В таком случае **запрещено** отдавать её пользователю или использовать в отчетах.
   - При ошибке продолжай поиск, ищи альтернативные ссылки или используй браузерный агент (browser subagent) для ручной навигации.
3. **Результат**:
   - Возвращай пользователю (или вызывающему скиллу) только ту информацию и ссылки, которые успешно прошли проверку скриптом `curl.ts`.
