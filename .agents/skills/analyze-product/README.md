# Навык анализа привлекательности товара (analyze-product)

Навык предназначен для всестороннего анализа товаров на Amazon (по скриншотам SellerAmp SAS, графикам Keepa, кодам ASIN или EAN) для оптовой торговли (Wholesale / FBA / FBM) с обязательной проверкой актуальных закупочных цен поставщиков в локальной базе данных.

---

## Ключевые возможности

1. **Автоматический поиск закупочной цены в БД:**
   - Поиск в таблице `DistributorPriceSnapshot` по EAN или ASIN.
   - Извлечение имени дистрибьютора, статуса, оптовой цены Netto и себестоимости с налогами.
   - Проверка наличия товара в контракте через представление `ContractedProductsView`.
2. **Оценка рисков по Keepa и SellerAmp:**
   - Доминирование Amazon (постоянное присутствие, неограниченный складской остаток `999+`).
   - Анализ истории цен и глубины возможных просадок (демпинг).
   - Оценка размера и риска перехода в категорию Oversize (габариты свыше 45x34x26 см).
   - Проверка ограничений аккаунта (Restricted/Ungate).
3. **Расчет двух сценариев юнит-экономики:**
   - **Сценарий А (С испанскими налогами):** `costPrice = priceNetto * 1.262` (IVA 21% + Recargo de Equivalencia 5.2%).
   - **Сценарий Б (Чистая цена Netto):** для компаний с зачетом НДС или поставками intra-EU (Reverse Charge).
   - Стресс-тест на случай падения розничной цены до исторического минимума Amazon.

---

## Быстрый запуск из командной строки

Для поиска закупочных цен конкретного товара в БД:

```bash
cd backend
npx tsx scripts/get-distributor-snapshot.ts <ASIN_или_EAN>
```

Примеры:
```bash
# Поиск по коду ASIN
npx tsx scripts/get-distributor-snapshot.ts B0HFKT8N24

# Поиск по штрихкоду EAN
npx tsx scripts/get-distributor-snapshot.ts 8412688672950
```

## Архитектура данных

- **Таблица `DistributorPriceSnapshot`:**
  - `distributorId` (Int, внешний ключ к таблице `Distributor`)
  - `asinId` (Int, внешний ключ к сопоставленному товару в таблице `ASIN`)
  - `ean` (String, штрихкод производителя)
  - `priceNetto` (Float, оптовая цена поставщика без НДС)
  - `costPrice` (Float, себестоимость с налогами Испании: `priceNetto * 1.262`)
  - `createdAt` (DateTime, дата загрузки прайс-листа)
- **Представление `ContractedProductsView`:**
  - Содержит актуальные маржинальности, чистую прибыль и комиссии Amazon для брендов в статусе `CONTRACTED`.
- **Таблица `KeepaApiProcessedData`:**
  - Содержит точные замеры габаритов упаковки (`packageLength`, `packageWidth`, `packageHeight`, `packageWeight`), комиссии FBA (`fbaFee`) и размерный класс (`sizeTier`).

## Критерии вердикта по закупке

1. **Категорический отказ (Не рекомендуется):**
   - Amazon продает товар сам и держит остаток `999+` по цене, близкой к минимальной рентабельности.
   - Чистая прибыль в Сценарии А отрицательная или менее 5% ROI.
   - Стресс-тест по исторической минимальной цене уводит сделку в убыток.
   - Листинг имеет возраст менее 1 месяца при отсутствии отзывов и неясном спросе.
2. **Условно рекомендовано:**
   - Экономика сходится только по чистой цене Netto (Сценарий Б), но по Сценарию А маржа около нуля.
   - Amazon периодически уходит в Out of Stock, позволяя сторонним селлерам забирать продажи по более высокой цене.
3. **Рекомендовано к закупке:**
   - Amazon отсутствует на листинге или делит Buy Box на равных условиях.
   - ROI в Сценарии А превышает 20%, маржинальность более 10%.
   - Стабильный BSR, есть органические продажи и отзывы.
