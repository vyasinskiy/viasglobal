# Инструкция для ИИ (Create Welcome Letter)

## Триггер активации
Этот навык должен активироваться, когда пользователь произносит фразу:
- **"сделай приветственное письмо"**
- **"сформируй приветственное письмо"**
- **"создай приветственное письмо"**
- или аналогичную по смыслу фразу для подготовки B2B-запроса поставщику/производителю.

---

## Входные данные и пошаговый опрос

Для формирования письма необходимы:
1. **Наименование поставщика / производителя** (`Manufacturer_name_or_distributor_name`).
2. **Список товаров** (список EAN кодов либо список ASIN). Количество может быть любым (1 и более).

### Алгоритм опроса:
- Если пользователь **не указал наименование поставщика/производителя**, спроси:
  > *«Укажите название производителя или дистрибьютора (например: Jerry Fabrics):»*
- Если пользователь **не указал товары (ASIN или EAN)**, спроси:
  > *«Укажите список ASIN или EAN товаров (через запятую или каждый с новой строки):»*
- Если в запросе пользователя уже есть часть данных, запрашивай **только недостающие**.

---

## Обработка товаров и получение EAN

1. **Если переданы EAN (числовые штрихкоды из 13 цифр):**
   - Используй их напрямую для подстановки в письмо в формате `- EAN <номер>`.

2. **Если переданы ASIN (10-значные коды, например `B0CW6FMW5M`):**
   - Запусти скрипт для извлечения EAN из базы данных через `run_command`:
     ```bash
     npx tsx .agents/skills/create-welcome-letter/scripts/get-eans-by-asins.ts <ASIN_1> <ASIN_2> ...
     ```
   - Скрипт вернет JSON сопоставления ASIN -> EAN из представления `AsinView`.
   - Если для какого-то ASIN штрихкод EAN не найден в БД, выведи предупреждение пользователю и подставь в письмо сам ASIN или запроси уточнение.

## Формирование письма

1. Прочитай актуальный шаблон из [`other/welcome_letter/template.md`](file:///Users/usuario/code/viasglobal/other/welcome_letter/template.md).
2. Заполни адрес получателя `To: {recipient_email}` (например, `To: info@jfabrics.cz`).
3. Замени плейсхолдер `{Manufacturer_name_or_distributor_name}` на название компании поставщика.
4. Замени блок `- EAN {number}` на реальный список полученных EAN (каждый с новой строки):
   ```text
   For reference, we are currently looking for the following items:
   - EAN 8592753035344
   - EAN 8592753033302
   - EAN 8592753039137
   ```
5. Сохрани сформированное письмо в файл:
   - Путь: `other/welcome_letter/letters/<Имя_Поставщика_в_lowercase_с_дефисами>.md` (например, `other/welcome_letter/letters/jerry-fabrics.md`).
   - Используй инструмент `write_to_file`.
6. Выведи готовое сформированное письмо в ответе пользователю в блоке `markdown` / `text` для удобного копирования, а также предоставь кликабельную markdown-ссылку на сохраненный файл.
7. **Предложение обновить статус дистрибьютора**:
   - В конце своего ответа **обязательно** добавь предложение обновить статус дистрибьютора в базе данных:
     > *«💡 После отправки письма вы можете обновить статус дистрибьютора в базе данных (произнесите: «я отправил письмо `<Название_дистрибьютора>`, обнови статус»).»*
   - Когда пользователь сообщает об отправке письма (например, «я отправил письмо [дистрибьютор]» или «обнови статус на отправлено»), выполни обновление записи дистрибьютора в таблице `Distributor`:
     - `status: DistributorStatus.EMAIL_SENT`
     - `lastContactAt: new Date()`
     - `email: <email_дистрибьютора>` (если известен)
8. **Запрет длинного тире (`—`)**:
   - В формируемом письме **строго запрещено использовать длинное тире `—` (em-dash)**, выдающее работу ИИ. Использовать только стандартный дефис `-` или естественную пунктуацию.
