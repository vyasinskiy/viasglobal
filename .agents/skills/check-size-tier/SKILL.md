# Установка и запуск (Только для AI)

Этот навык активируется, когда пользователь просит проверить размерную сетку (Size Tier) для конкретного ASIN. (Например: "скажи мне размер асина B012345678", "проверь размер B012345678").

## Описание

Скрипт проверяет наличие ASIN в локальной базе (`KeepaApiProcessedData`), а если его там нет, обращается напрямую к Keepa API (Region: ES), извлекает габариты и вес, и прогоняет их через нашу функцию `calculateAmazonTier`. Результат выводится в консоль.

## Инструкция по выполнению

1. Извлеки ASIN из запроса пользователя.
2. Перейди в папку `backend` и выполни команду:
   ```bash
   npx tsx scripts/check-size-tier.ts <ASIN>
   ```
3. Дождись выполнения скрипта.
4. Проанализируй вывод:
   - Если данные были в БД, скрипт выведет габариты и вычисленный класс размера (например, `Standard parcel`).
   - Если данных не было, скрипт запросит Keepa API напрямую и выведет сырые данные (в миллиметрах и граммах) вместе с результатом вычисления.
5. Ответь пользователю, четко указав:
   - Найденные габариты и вес.
   - Вычисленный **Size Tier**.
   - Предложи пользователю сверить этот результат с интерфейсом SellerAmp SAS и сообщить тебе, если есть расхождения, чтобы мы могли скорректировать формулу в коде.
