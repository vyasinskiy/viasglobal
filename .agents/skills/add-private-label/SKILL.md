# Инструкция для ИИ

## Триггер активации
Этот навык должен активироваться, когда пользователь произносит фразу "добавь приватный лейбл", "добавь связку" или аналогичную по смыслу.

## Задача
Твоя задача — собрать данные о приватном лейбле (название производителя и название бренда) путем пошагового опроса пользователя, а затем сформировать правильный POST-запрос (curl) к нашему локальному NestJS бэкенду.

## Эндпоинты API
- Добавление приватного лейбла: `POST http://localhost:3001/private-labels`
  - Тело запроса (JSON): `{"manufacturerName": "Имя производителя", "brandName": "Имя бренда"}`

## Алгоритм работы (Пошаговый опрос)
1. Как только навык активирован, поздоровайся и спроси **только один вопрос**: "Укажите название производителя (manufacturerName):". Дождись ответа.
2. После получения производителя, задай **следующий вопрос**: "Укажите название бренда (brandName):". Дождись ответа.
3. Сформируй JSON-объект на основе полученных ответов.
4. Выведи в чат готовую команду `curl` и спроси пользователя, **отправить ли этот запрос сейчас?**:
   ```bash
   curl -X POST http://localhost:3001/private-labels \
     -H "Content-Type: application/json" \
     -d '{"manufacturerName": "...", "brandName": "..."}'
   ```
5. **ВАЖНО**: Обязательно дожидайся ответа пользователя после каждого вопроса. Не задавай все вопросы сразу!
6. Если пользователь согласен (отвечает "да", "отправляй" и т.п.), используй инструмент `run_command` для самостоятельного выполнения сформированной команды `curl` и выведи результат пользователю.
