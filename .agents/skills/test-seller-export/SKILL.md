# Инструкция по тестированию выгрузки продавца (test-seller-export)

Этот навык автоматизирует процесс проверки корректности фильтров в нашем API путем сравнения результатов автоматической выгрузки из Keepa с ручной выгрузкой через веб-интерфейс Product Finder.

## Алгоритм работы (строго следовать по шагам)

**Шаг 1: Определение имени продавца**
- Если пользователь не указал имя продавца при вызове навыка, вежливо спроси: "Какого продавца вы хотите протестировать?"
- Дождись ответа.

**Шаг 2: Поиск `sellerId` в базе данных**
- Как только имя продавца станет известно, найди его `sellerId` в базе данных. Для этого используй прямое подключение к боевой БД:
  `psql "postgresql://viasuser:viaspassword@100.92.50.18:5432/viasglobal_db" -c "SELECT id, name FROM \"Seller\" WHERE name ILIKE '%<ИМЯ_ПРОДАВЦА>%';"`
- Сообщи пользователю найденный `sellerId` (это строка вида `A1O61CEYQ8IRTV`).

**Шаг 3: Инструкция для пользователя**
- Отправь пользователю ссылку на Keepa: [https://keepa.com/#!finder](https://keepa.com/#!finder)
- Напиши пользователю следующую инструкцию:
  > 1. Откройте **Keepa Product Finder** по ссылке выше.
  > 2. Пролистайте вниз до раздела **Refine your search**.
  > 3. Найдите поле **"Specific seller(s) - seller ID"** и вставьте туда ID: `<ТУТ_НАЙДЕННЫЙ_SELLER_ID>`.
  > 4. Нажмите **"FIND PRODUCTS"**.
  > 5. Нажмите кнопку **"Export"**, выберите формат **CSV** (All active columns) и скачайте файл.
  > 6. Положите скачанный файл в папку проекта и напишите мне путь к нему!

**Шаг 4: Запуск автоматического сравнения**
- Когда пользователь предоставит путь к скачанному файлу (например, `backend/scripts/export.csv`), запусти скрипт сравнения из корня папки `backend` (или используй полный путь из корня):
  `npx tsx backend/scripts/compare-keepa-seller.ts <SELLER_ID> <ПУТЬ_К_ФАЙЛУ>`
- Проанализируй вывод скрипта. Обрати внимание на процент совпадения и списки отсутствующих ASIN.
- Предоставь пользователю краткий отчет и предложи обсудить расхождения (например, если API нашло меньше товаров, возможно, в нашем `payload` стоят более строгие фильтры по Sales Rank или Buy Box, чем пользователь ставил вручную).
