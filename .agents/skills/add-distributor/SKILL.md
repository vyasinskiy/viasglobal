# Инструкция для ИИ

## Задача
Пользователь передает тебе данные о найденном дистрибьюторе (название, сайт, опционально связанный бренд). Твоя задача — сформировать правильный POST-запрос (curl) к нашему локальному NestJS бэкенду.

## Эндпоинты API
- Добавление дистрибьютора: `POST http://localhost:3000/distributors`
  - Тело запроса (JSON): `{"name": "Имя", "website": "Сайт", "brandName": "Бренд (опционально)"}`

## Алгоритм работы
1. Прими данные от пользователя (например, из результатов работы `find-distributor`).
2. Сформируй JSON-объект.
3. Выведи в чат готовую команду `curl`:
   ```bash
   curl -X POST http://localhost:3000/distributors \
     -H "Content-Type: application/json" \
     -d '{"name": "...", "website": "...", "brandName": "..."}'
   ```
4. **ВАЖНО**: НЕ пытайся выполнить эту команду самостоятельно через инструмент терминала! Пользователь строго указал, что он должен выполнить её вручную. Твоя задача только сгенерировать текст команды.
