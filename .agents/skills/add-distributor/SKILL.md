# Инструкция для ИИ

## Триггер активации
Этот навык должен активироваться, когда пользователь произносит фразу "добавь поставщика" (или аналогичную по смыслу).

## Задача
Твоя задача — собрать данные о дистрибьюторе (название, сайт, связанный бренд) путем пошагового опроса пользователя, а затем сформировать правильный POST-запрос (curl) к нашему локальному NestJS бэкенду.

## Эндпоинты API
- Добавление дистрибьютора: `POST http://localhost:3001/distributors`
  - Тело запроса (JSON): `{"name": "Имя", "website": "Сайт", "brandName": "Бренд (опционально)", "isPrivateLabel": true/false}`

## Алгоритм работы (Пошаговый опрос)
1. Как только навык активирован, поздоровайся и спроси **только один вопрос**: "Укажите название дистрибьютора (name):". Дождись ответа.
2. После получения названия, задай **следующий вопрос**: "Укажите сайт дистрибьютора (website):". Дождись ответа.
3. После получения сайта, задай **следующий вопрос**: "Укажите связанный бренд (brandName), если есть. Если нет, напишите 'нет' или пропустите:". Дождись ответа.
4. После ответа о бренде, задай **последний вопрос**: "Является ли он приватным лейблом (isPrivateLabel)? (да/нет):". Дождись ответа.
5. Сформируй JSON-объект на основе полученных ответов (isPrivateLabel должен быть булевым значением: true/false).
6. Выведи в чат готовую команду `curl` и спроси пользователя, **отправить ли этот запрос сейчас?**:
   ```bash
   curl -X POST http://localhost:3001/distributors \
     -H "Content-Type: application/json" \
     -d '{"name": "...", "website": "...", "brandName": "...", "isPrivateLabel": false}'
   ```
7. **ВАЖНО**: Обязательно дожидайся ответа пользователя после каждого вопроса. Не задавай все вопросы сразу!
8. Если пользователь согласен (отвечает "да", "отправляй" и т.п.), используй инструмент `run_command` для самостоятельного выполнения сформированной команды `curl` и выведи результат пользователю.
