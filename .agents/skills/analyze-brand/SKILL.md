# Инструкция для ИИ (Analyze Brand)

## Триггер активации
Этот навык должен активироваться при фразах:
- **"добавь легенду для бренда [Название]"**
- **"вот асины для бренда [Название]"**
- Или когда пользователь передает ASIN'ы и комментарии по позиционированию товаров бренда для магазина.

## Задача
Пользователь вручную отбирает привлекательные ASIN из каталога бренда, которые хорошо вписываются в концепцию (легенду/подборку) нашего интернет-магазина (например, "товары для пляжа", "подарки к празднику"). Эти идеи нужно сохранить в базу данных, чтобы в дальнейшем навык `create-welcome-letter` мог опираться на них при составлении уникального B2B-запроса поставщику.

## Алгоритм работы
1. **Сбор данных**: 
   - Выдели из запроса пользователя название бренда, список ASIN и комментарий (идею/легенду).
2. **Формирование заметки**:
   - Сформируй итоговый текст для сохранения в базу данных. Пример: `Легенда для Welcome Letter: В основном инструмент, но интересуют товары для кемпинга (портативный холодильник, газовая горелка). ASIN: B001..., B002...`
3. **Обновление базы данных (Запрос разрешения)**:
   - Согласно правилу проекта "Запрет на запись без спроса", создай временный скрипт в `backend/scripts/temp/update-brand-notes.ts`, который с помощью PrismaClient обновляет поле `notes` у модели `Brand` по названию бренда.
   - Скрипт должен выглядеть примерно так:
     ```typescript
     import { PrismaClient } from '@prisma/client';
     import { PrismaPg } from '@prisma/adapter-pg';
     import { Pool } from 'pg';
     import * as dotenv from 'dotenv';
     dotenv.config();

     const connectionString = process.env.DATABASE_URL || 'postgresql://viasuser:viaspassword@localhost:5432/viasglobal_db?schema=public';
     const pool = new Pool({ connectionString });
     const adapter = new PrismaPg(pool);
     const prisma = new PrismaClient({ adapter });

     async function main() {
       const brandName = 'ИМЯ_БРЕНДА';
       const targetBrand = await prisma.brand.findFirst({
         where: { name: { equals: brandName, mode: 'insensitive' } }
       });
       
       if (!targetBrand) {
         console.error(`Бренд ${brandName} не найден`);
         process.exit(1);
       }

       // Дописываем новую легенду к старым заметкам, если они есть
       const newNotes = targetBrand.notes ? `${targetBrand.notes}\n\nЛегенда: ТВОЙ_ТЕКСТ` : `Легенда: ТВОЙ_ТЕКСТ`;

       await prisma.brand.update({
         where: { id: targetBrand.id },
         data: { notes: newNotes }
       });
       console.log('Успешно обновлено!');
       await prisma.$disconnect();
       await pool.end();
     }
     main().catch(console.error);
     ```
   - **ОБЯЗАТЕЛЬНО** спроси у пользователя разрешение на выполнение этого скрипта.
4. **Выполнение скрипта**:
   - После согласия пользователя, запусти скрипт через `run_command` (находясь в директории `backend/`).
   - После успешного выполнения удали временный скрипт (согласно правилу уборки мусора).
5. **Подтверждение**:
   - Сообщи пользователю, что легенда сохранена в базу. Напомни, что теперь при вызове `сделай приветственное письмо`, ИИ автоматически подтянет эту легенду и сделает упор на нужные категории товаров.
