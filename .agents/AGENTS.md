# Требования к проекту (Viasglobal)

- **Язык**: Все комментарии в коде и документация (README) должны быть на **русском языке**.
- **Стек**: Next.js (App Router), Vanilla CSS + Material-UI (MUI).
- **Дизайн**: 
  - Использовать цвета, близкие к Amazon (оранжевый, черный, белый, темно-синий/серый), для обеспечения консистентности.
  - Дизайн должен быть современным (с использованием CSS variables).
- **GDPR compliance (Евросоюз/Испания)**: 
  - Наличие баннера согласия на использование Cookie.
  - Страницы Политики конфиденциальности, Условий использования (Aviso Legal) и Политики файлов cookie.
- **Контакты**: Вместо формы обратной связи использовать простую кнопку `mailto:` с адресом `info@viasglobal.es`. Все контактные данные (имейл, домен viasglobal.es, название компании) выносить в переменные/константы, чтобы их было легко менять.
- **Хостинг**: Деплой на Vercel (стандартный билд, $0/мес).

## Правила документирования

- **Архитектура подпроектов**: Проект состоит из подпроектов (например, `landing`, `signature`, `keepa` и т.д.). Внутри каждого подпроекта **обязательно** должны быть свои собственные файлы `AGENTS.md` (инструкции для ИИ) и `README.md` (документация для человека).
- **Чтение локальных инструкций**: Если запрос пользователя относится к определенному подпроекту, я (ИИ) **обязан первым делом прочитать вложенный файл `AGENTS.md`** и соответствующий `README.md` этого подпроекта, чтобы получить контекст, прежде чем писать код или давать советы.
- **Запись ответов на вопросы**: Любые важные ответы на вопросы или решения проблем, касающиеся конкретной части проекта, должны обязательно записываться в локальный `AGENTS.md`. Я не должен просто отдавать ответ в чате, я обязан сохранить это знание в код.
- **Двойная документация**: Когда пользователь уточняет ссылки, бизнес-логику или требования, я обязан поддерживать в актуальном состоянии **ОБА** файла подпроекта: `README.md` (подробное описание) и `AGENTS.md` (короткие правила для ИИ).
