# Email Signature (Viasglobal)

В этой директории хранится HTML-подпись для электронной почты.

## Особенности
- Подпись свёрстана с использованием устаревшей табличной структуры (тэги `<table>`, `<tr>`, `<td>`), чтобы гарантировать корректное отображение в старых десктопных почтовых клиентах (например, старых версиях Outlook).
- Текст подписи написан на **английском языке**.
- Имя: Vitalii Iasinskii
- Должность: Managing Director
- Все картинки (логотипы) подгружаются с сервера по абсолютным путям. **Важно**: Основной логотип всегда должен ссылаться строго на `https://viasglobal.es/logo.png`. Файл логотипа задеплоен в `shop/public/logo.png` специально для того, чтобы подпись работала надежно и ее не нужно было менять. Менять этот URL запрещено.
