# Инструкции для ИИ (Other)

*Правила для ИИ:*
1. В директории `other/` хранятся вспомогательные материалы (шаблоны писем, HTML-подписи и т.д.).
2. При добавлении новых вспомогательных разделов обязательно создавать в них собственные файлы `README.md` (на русском языке) и `AGENTS.md`.
3. Сохранять форматирование и языковые требования для каждого подраздела (например, английский язык для текстов писем и подписей, русский язык для документации).
