# Локальные ИИ-навыки (Skills)

В этой директории мы храним или проектируем кастомные инструкции для ИИ-агентов (skills), которые специфичны только для этого проекта (например, скрипты парсинга, автоматизация создания отчетов по Excel файлам и т.д.).

Если вы хотите, чтобы навыки загружались системой автоматически при запуске агента в этом проекте, они должны лежать внутри директории `.agents/skills/`. Эта же папка (`skills/`) предназначена в первую очередь для черновиков, хранения референсов или если вы не хотите автоматической подгрузки.
