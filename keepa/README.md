# Данные Keepa (Парсинг)

В этой директории хранятся выгрузки (в форматах Excel, CSV и т.д.) из сервиса Keepa или других аналитических инструментов для работы на платформе Amazon.

Эти файлы используются для автоматического и ручного анализа, поиска производителей и европейских дистрибьюторов (wholesale sourcing).
