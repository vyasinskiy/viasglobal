# Документация и правила для лендинга

## Особенности деплоя (Vercel)

Поскольку весь код Next.js был перемещен из корня проекта в директорию `landing`, стандартный процесс деплоя Vercel требует небольшого изменения конфигурации.

В панели управления Vercel необходимо изменить "Root Directory" проекта:
1. Зайдите в проект на Vercel ([https://vercel.com/viasglobal](https://vercel.com/viasglobal)).
2. Откройте **Settings** -> **General**.
3. В разделе **Root Directory** впишите `landing` и сохраните.

Если этого не сделать, Vercel попытается собрать проект из пустого корня и деплой сломается.
