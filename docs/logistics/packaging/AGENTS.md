## 2. Стандарты упаковки Amazon FBM для товаров в заводских коробках
- Заводские витринные коробки малой бытовой техники (фены, утюги) **запрещено отправлять открытыми или обклеенными скотчем перевозчика**.
- Обязательно упаковывать в непрозрачные трехслойные курьерские пакеты (*Bolsas de mensajería opacas*) с перманентным клеевым клапаном либо самосборные коробки.
- Транспортная этикетка (100×150 мм Correos / SEUR / MRW) клеится строго на внешнюю поверхность курьерского пакета.

## 3. Расчёт совместимости коробки $(L \times W \times H)$ с курьерским пакетом $(W_{bag} \times L_{bag})$:
1. **Ширина пакета (горловина):**
   $$W + H \le W_{bag}$$
2. **Рабочая глубина пакета:**
   $$L + \frac{1}{2} H \le L_{bag}$$
- Пример для утюга Kuken ($31.5 \times 17.5 \times 13\text{ см}$):
  - По ширине: $17.5 + 13 = 30.5\text{ см} \le 40\text{ см}$ (запас +9.5 см).
  - По глубине: $31.5 + 6.5 = 38.0\text{ см} \le 50\text{ см}$ (запас +12.0 см до клеевого клапана).
