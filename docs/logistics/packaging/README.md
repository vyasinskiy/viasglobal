# Руководство по упаковке e-commerce и фулфилменту (Packaging Guide)

> **Статус модуля:** Общепроектный стандарт логистики и упаковки товаров для электронной коммерции (FBM, FBA и собственный интернет-магазин).  
> **Применимость:** Все бренды, поставщики и номенклатурные группы каталога Viasglobal.

---

## 1. Задачи и принципы упаковки

Качественная упаковка решает три ключевые бизнес-задачи:
1. **Защита рейтинга продавца (Account Health):** Нулевой процент возвратов из-за повреждений в пути, удержание показателя дефектов заказов (*Order Defect Rate*) ниже 1%.
2. **Оптимизация логистических затрат:** Минимизация габаритного объёма и веса посылки для попадания в минимальные тарифные сетки испанских перевозчиков (Correos, SEUR, MRW, GLS, DHL).
3. **Соответствие нормативам ЕС и маркетплейсов:** Соблюдение директив безопасной упаковки Amazon FBA/FBM и европейских экологических регламентов (EPR, PPWR).

---

## 2. Расчёт объёмного веса (Peso Volumétrico) у перевозчиков Испании

При расчёте стоимости доставки транспортные компании тарифицируют отправление по **наибольшему** из двух показателей:
* **Фактический вес (Peso Real):** Вес брутто на весах (товар + коробка/пакет).
* **Объёмный вес (Peso Volumétrico):** Расчётный вес, занимаемый посылкой в курьерском транспорте.

### Формула расчёта в Испании:
Большинство экспресс-перевозчиков Испании (SEUR, MRW, GLS, DHL, UPS) используют коэффициент пересчета **5000** (у Correos для посылок Paq Estándar/Premium может применяться делитель 6000):

$$\text{Объёмный вес (кг)} = \frac{\text{Длина (см)} \times \text{Ширина (см)} \times \text{Высота (см)}}{5000}$$

### Сравнение тары: Курьерский пакет (*Mailer*) vs Коробка (*Caja*)

На примере компактного текстильного изделия (рюкзак или худи 27×33 см, реальный вес 0.28 кг):

| Параметр | Самосборная коробка (*Caja 30×35×12 см*) | Курьерский пакет (*Bolsa 35×45 см, толщина ~6 см*) |
| :--- | :--- | :--- |
| **Собственный вес упаковки** | ~0.25 кг | ~0.04 кг |
| **Фактический вес брутто** | **0.53 кг** | **0.32 кг** |
| **Расчётный объёмный вес** | $(30 \times 35 \times 12) / 5000 =$ **2.52 кг** | $(35 \times 45 \times 6) / 5000 =$ **1.89 кг** (в Correos до 1.3 кг) |
| **Тарифицируемый вес** | Тариф до **3 кг** (у экспресс-служб) | Тариф до **1–2 кг** |
| **Экономия на 1 отправке** | Базовый тариф | **Дешевле на 1.00–2.00 € за посылку** |
| **Трудозатраты на сборку** | Сложить коробку, проклеить скотчем | Вложить, снять защитную ленту, прижать клапан |

> **Вывод:** Для сжимаемого текстиля и мягких товаров без хрупких деталей приоритетом всегда является **Bolsa mensajero opaca coextruida**. Картонная коробка применяется только при наличии хрупких/деформируемых элементов (например, 3D-термоформованных панелей) либо для премиальных хрупких линеек.

## 3. Матрица выбора упаковочного решения

| Категория товара | Внутренняя защита | Внешняя тара | Когда переходить на коробку |
| :--- | :--- | :--- | :--- |
| **Мягкий текстиль** (одежда, пеналы, мягкие рюкзаки) | Полиэтиленовый пыльник *galga 100* с предупреждением об удушье | Пакет курьерский непрозрачный *galga 60* | По желанию клиента (подарочная упаковка) |
| **Текстиль с объемными деталями** (рюкзаки с 3D-накладками, формованные сумки) | Пыльник *galga 100* + крафт-бумага на лицевую панель | Пакет курьерский (если дроп-тест пройден) | Если при дроп-тесте или давлении 5 кг вминается панель $\rightarrow$ коробка *microcanal* |
| **Хрупкие предметы** (посуда, пластик, электроника) | Пузырчатая пленка (*plástico de burbujas*) толщиной 1–2 слоя | Самосборная коробка *caja microcanal* + крафт-бумага в пустоты | Коробка обязательна всегда |
