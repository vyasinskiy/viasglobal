# Viaslangs - Сервис изучения и повторения языков

Веб-приложение для интервального повторения иностранных слов и профессиональной бизнес-лексики (английский и испанский языки).

---

## Архитектура и структура подпроекта

Проект разделен на три основных компонента:

- **`web/`**: современный веб-интерфейс на Next.js (App Router, Tailwind CSS, Material UI) для карточек повторения, списков слов, статистики и тегов.
- **`server/`**: REST API бэкенд на Node.js / Express и Prisma ORM, подключенный к базе данных PostgreSQL.
- **`client/`**: React SPA клиент (Vite / CRA).

### Схема базы данных (PostgreSQL)

- **`vy_languages`**: поддерживаемые языки (`code`: `en`, `es`).
- **`vy_words`**: карточки слов:
  - `english`: исходное слово / фраза на целевом языке (испанский или английский).
  - `russian`: перевод на русский язык.
  - `example_en` (`exampleEn`): контекстный пример предложения на целевом языке.
  - `example_ru` (`exampleRu`): перевод примера на русский язык.
  - `base_word_id` (`baseWordId`): ссылка на базовый инфинитив глагола для спряжённых форм времён.
  - `is_favorite`: признак избранного слова.
- **`vy_tags`**: тематические и грамматические теги (привязаны к `language_id`).
- **`vy_word_tags`**: связь слов с тегами (многие-ко-многим).
- **`vy_answers`**: история ответов и статистика правильных/неправильных попыток.

## Тематические паки слов и теги

Все слова группируются по тегам для сфокусированного изучения (например, по темам общения с поставщиками или по грамматическим категориям).

### Принцип анализа тегов и множественного тегирования:
- **Множественная привязка (M2M)**: одно слово может иметь неограниченное число тегов одновременно через таблицу `vy_word_tags`.
- **Предварительный анализ существующих тегов**: перед добавлением любого нового пакета слов выполняется автоматический анализ существующих в базе тегов для данного языка (`vy_tags`).
- **Грамматическое и тематическое тегирование**: каждое слово сопоставляется с имеющимися тегами. Например, если добавляется слово-глагол, оно обязательно привязывается к тегу «Глаголы», а также к профильному тематическому тегу своего набора.
- **Дедупликация слов (Контроль повторов)**: перед вставкой всегда выполняется проверка по `lower(english)`. Если слово уже существует в таблице `vy_words`, оно не дублируется. При необходимости к нему лишь привязываются недостающие теги.

### Долговременное сохранение языка и тега в Cookie (400 дней)
- Приложение сохраняет последний выбранный язык и активный тег прямо в cookies браузера (`vias_last_language_id`, `vias_last_tag_id` и `vias_last_tag_id_${languageId}`).
- Срок хранения - 400 дней (`max-age=34560000`, `SameSite=Lax`, `path=/`).
- Предусмотрен fallback на `localStorage`.
- При повторном открытии сайта или обновлении вкладки язык и последний используемый тег восстанавливаются мгновенно, до старта запросов к тренажеру, что исключает мигание экрана.
- Теги привязаны к конкретному языку: при переключении между языками автоматически активируется последний тег, использовавшийся именно для этого языка.
- При выборе «All words» («Все слова») куки последнего тега очищается (`max-age=0`).

## Управление и удаление карточек слов

- **Удаление из карточки изучения (`StudyCard`)**:
  * Через иконку корзины («Delete word») в верхней панели действий рядом с избранным и редактированием.
  * Через кнопку «Delete» с иконкой корзины в левом нижнем углу модального окна редактирования слова («Edit Word»).
- **Подтверждение и переход**: при нажатии запрашивается подтверждение браузера (`window.confirm`), после чего слово удаляется через `DELETE /api/words/:id`, таймеры сбрасываются, а тренажер сразу переходит к следующему слову.
- **Удаление в общем списке (`WordList`)**: удаление доступно как отдельной иконкой в строке таблицы, так и внутри модального окна редактирования слова.

## Спряжения времён испанского языка и автозачёт (Pretérito Indefinido / Imperfecto)

### Архитектура связи форм (`base_word_id`)
- Для 50 ключевых испанских B2B-глаголов созданы карточки спряжения во всех 6 лицах (`yo`, `tú`, `él/ella/usted`, `nosotros`, `vosotros`, `ellos/ellas/ustedes`) для двух прошедших времен: `Pretérito Indefinido` и `Pretérito Imperfecto` (всего 600 карточек).
- Каждая спряженная форма связана с базовым инфинитивом через колонку `base_word_id` (`vy_words.base_word_id = base_verb.id`). У самого инфинитива `base_word_id IS NULL`.
- Каждая карточка времени привязана минимум к 3 тегам:
  1. Тег конкретного времени (`Pretérito Indefinido` или `Pretérito Imperfecto`).
  2. Грамматический тег `Глаголы`.
  3. Профильный тематический тег пака (`Для общения с поставщиками`).

### Бизнес-логика автозачёта (Auto-complete)
При тренировке конкретного времени пользователю не требуется вводить все 6 лиц подряд:
1. При правильном ответе пользователя (`is_correct = true`) на любую форму глагола (например, 3-е лицо `envió`), бэкенд в `POST /api/answers/check` автоматически добавляет правильные ответы (`is_correct = true`) для всех остальных 5 лиц этого глагола в рамках данного времени.
2. **Изоляция времен**: выборка автозачёта явно фильтрует теги времени (`t.name IN ('Pretérito Indefinido', 'Pretérito Imperfecto')`). Формы других времен того же глагола (например, Imperfecto при ответе на Indefinido) не затрагиваются.
3. **Изоляция глаголов**: автозачёт фильтруется по `w2.base_word_id = $1`, поэтому формы других глаголов не затрагиваются.
4. **Идемпотентность**: благодаря условию `NOT EXISTS (SELECT 1 FROM vy_answers a WHERE a.word_id = w2.id AND a.is_correct = true)`, повторные ответы не приводят к дублированию записей.
5. **Исключение из Study**: режим изучения `/api/words/study` отбирает только неизученные слова (`NOT EXISTS ... is_correct = true`). Поэтому после автозачёта все 6 форм глагола в данном времени сразу исключаются из очереди изучения.

```sql
INSERT INTO vy_answers (word_id, answer, is_correct)
SELECT DISTINCT w2.id, w2.english, true
FROM vy_words w2
JOIN vy_word_tags wt2 ON wt2.word_id = w2.id
WHERE w2.base_word_id = $1
  AND w2.id != $2
  AND wt2.tag_id IN (
    SELECT t.id
    FROM vy_word_tags wt
    JOIN vy_tags t ON t.id = wt.tag_id
    WHERE wt.word_id = $2
      AND t.name IN ('Pretérito Indefinido', 'Pretérito Imperfecto')
  )
  AND NOT EXISTS (
    SELECT 1 FROM vy_answers a WHERE a.word_id = w2.id AND a.is_correct = true
  )
```

## Тестирование логики

Логика автозачёта жестко покрыта интеграционными тестами на реальных данных базы PostgreSQL.

### Запуск тестов:
```bash
npm --prefix viaslangs/web test
```

### Список тестов (`viaslangs/web/tests/tenses-auto-complete.test.mjs`):
1. **Базовый правильный глагол (`enviar`, Indefinido)**: верный ответ на 3-е лицо `envió` автоматически засчитывает все 6 форм (`envié`, `enviaste`, `envió`, `enviamos`, `enviasteis`, `enviaron`).
2. **Изоляция времён**: формы того же глагола в `Pretérito Imperfecto` (`enviaba`, `enviabas`, ...) остаются нетронутыми.
3. **Изоляция других глаголов**: формы глаголов `pedir`, `pagar` и `producir` в Indefinido не затрагиваются.
4. **Поведение при ошибке**: при неверном ответе (например, `pido` вместо `pedí`) автозачёт не срабатывает, фиксируется 1 ошибка.
5. **Глагол с чередованием e->i (`pedir`, Indefinido)**: верный ответ на форму 3-го лица `pidió` автозачитывает все 6 форм (`pedí`, `pediste`, `pidió`, `pedimos`, `pedisteis`, `pidieron`).
6. **Тренировка в Pretérito Imperfecto (`pedir`)**: ответ на форму 1-го лица мн. ч. `pedíamos` автозачитывает все 6 форм Imperfecto, не затрагивая Indefinido и другие глаголы.
7. **Нерегулярный j-глагол (`producir`, Indefinido)**: проверка нечувствительности к регистру и пробелам (`"  PRODUJE  "`), автозачёт всех 6 форм (`produje`, `produjiste`, `produjo`, `produjimos`, `produjisteis`, `produjeron`).
8. **Орфографическая замена g->gu (`pagar`, Indefinido)**: ответ на форму 1-го лица `pagué` успешно автозачитывает все 6 форм.
9. **Идемпотентность и защита от дубликатов**: повторный верный ответ на форму `pagaste` для уже закрытого глагола не создает дублирующих записей в таблице ответов.
10. **Обычные слова без `base_word_id`**: верный ответ на базовый инфинитив `enviar` не запускает автозачёт других слов.
11. **Интеграция с режимом Study**: эндпоинт `/api/words/study` сразу исключает все 6 автозачтенных форм глагола из списка неизученных слов.
12. **Нечувствительность к графическим знакам ударения (акцентам)**: разница между `ó` и `o`, `á` и `a`, `é` и `e`, `í` и `i`, `ú` и `u` игнорируется при проверке. Ввод `acepto` для формы `aceptó` признается верным и автозачитывает все 6 форм `aceptar`.

### Обязательное покрытие автотестами любых конкретных кейсов пользователя
Любые краевые случаи, особенности ввода или конкретные примеры, озвученные пользователем (например, обработка символов `ó` vs `o` на глаголе `acepto` -> `aceptó`), **в обязательном порядке фиксируются в виде отдельных тест-кейсов** в `tenses-auto-complete.test.mjs`. Это гарантирует надежную защиту от регрессий и сохранение утвержденной бизнес-логики.

## Сид-скрипты в `server/prisma/`:
- **`seed-es-verbs.sql`**: топ-50 ключевых испанских глаголов для B2B общения с поставщиками.

- **`seed-es-tenses.sql`**: создание тегов `Pretérito Indefinido` и `Pretérito Imperfecto`, добавление 600 форм спряжения для 50 глаголов с B2B-примерами и привязкой `base_word_id`.

## Аутентификация и бессрочная сессия

- **Пароль приложения**: настраивается через переменную `VIASLANGS_APP_PASSWORD` в `.env.local` (дефолт: `viasglobal`).
- **Бессрочная скользящая сессия**: токен сессии подписывается HMAC-SHA256 сроком на 20 лет (`SESSION_TTL_MS`), а в браузере выставляется защищенная кука `vias_session` со сроком 400 дней (максимально допустимый лимит Chromium/WebKit).
- **Автоматическое продление**: при каждом переходе по страницам middleware-прокси (`proxy.ts`) автоматически продлевает срок куки еще на 400 дней вперед и обновляет старые токены, исключая необходимость регулярного повторного ввода пароля.

## Мобильная верстка и адаптивность

Весь веб-интерфейс сервиса (`web/`) оптимизирован для комфортного использования на смартфонах и планшетах:

- **Адаптивная шапка (AppBar)**:
  - На мобильных экранах (`xs` < 600px) селекторы языка и паков тегов аккуратно перестраиваются во вторую строку, а кнопка выхода вынесена в правый верхний угол. Это полностью исключает сжатие заголовка и обрезку селекторов.
  - На планшетах (`sm`, 600px - 899px, включая 786px) используется компактное брендовое название `Viaslangs`, поля селекторов ограничены по максимальной ширине с обрезкой длинных тегов через многоточие (`ellipsis`), а кнопка выхода зафиксирована (`flexShrink: 0`). Это полностью решает проблему переполнения шапки на планшетах.
  - На десктопе (`md` от 900px) сохраняется просторная однострочная компоновка с полным названием `VIAS - Langs learning application`.
- **Тренажер слов (StudyCard)**:
  - Ширина карточки адаптивна: `width: '100%', maxWidth: 800` (без фиксированных 800px), что исключает горизонтальную прокрутку на любых устройствах.
  - Кнопка проверки ответа «Check Answer» масштабирована на всю ширину карточки для удобного тапа пальцем.
  - Вспомогательные действия «Show Answer» и «Next» расположены компактной парой под основной кнопкой.
  - Бейдж подсказки «Tap to reveal» гармонично встроен в заголовок контекстного примера, не перекрывая текст.
  - Снекбар прогресса центрирован для мобильных экранов.
- **Список слов (WordList)**:
  - На экранах телефонов громоздкая 7-колоночная таблица автоматически заменяется карточками слов с быстрым доступом к избранному, редактированию, удалению и примерам предложений.
  - На десктопе доступна классическая полноразмерная таблица.
- **Статистика (StatsComponent)**:
  - 2-колоночная сетка ключевых метрик на мобильных экранах позволяет видеть весь прогресс без длинного скролла.
  - Кнопки экспорта правильных слов за сегодня и сброса ответов удобно адаптируются под ширину экрана.

## Ежедневные сессии изучения, учет кликов Next и OpenClaw аналитика

В приложении реализована система учета ежедневной активности и аналитики ошибок:

### 1. Сессионные дни и клики Next
- Каждый календарный день для выбранного языка автоматически открывается новый сессионный день в таблице `vy_study_sessions`.
- При каждом клике на кнопку «Next» инкрементируется счетчик `next_clicks`, отражающий количество прочитанных примеров и попыток перехода между карточками.
- В журнал `vy_session_activities` фиксируются только прямые действия пользователя: клики `NEXT`, правильные ответы `ANSWER_CORRECT` и ошибки `ANSWER_ERROR` (без загрязнения автозачтенными формами).

### 2. Грамматический анализ ошибок по тегам и формам лица
- Модуль `lib/grammar.ts` автоматически сопоставляет каждую ошибку с:
  * Временем глагола из тегов карточки (`Pretérito Indefinido`, `Pretérito Imperfecto` и др.).
  * Грамматическим лицом из скобок русского перевода: `(я)` -> `yo`, `(ты)` -> `tú`, `(он / Вы)` -> `él/ella/usted`, `(мы)` -> `nosotros`, `(вы)` -> `vosotros`, `(они / Вы)` -> `ellos/ellas/ustedes`.
- Это позволяет выявлять проблемные зоны (например, «больше всего ошибок во времени Pretérito Indefinido на форме 1-го лица yo»).

### 3. API для автономного AI-ассистента OpenClaw
- **`POST /api/sessions/activity`**: регистрация активности в текущей сессии (`NEXT`, `ANSWER_CORRECT`, `ANSWER_ERROR`).
- **`GET /api/sessions/today`**: детальная статистика за сегодня с готовой текстовой рекомендацией (`recommendation`), списком слабых слов (`weakWords`) и точностью.
- **`GET /api/sessions/history?days=7`**: подневная история за 7-30 дней, расчет средней и **медианной дневной активности** за 7 дней (`medianDailyActivities`), флаги `isBelowMedian` и `shouldRemind`, тренд (`DROPPING`, `STABLE`, `GROWING`, `INACTIVE`) и готовый текст алерта для Telegram при снижении активности ниже медианной нормы:
  > *«Виталий, у тебя сегодня низкая активность по испанскому: всего 12 действий при медианной норме 20 за последние 7 дней. Давай позанимаемся испанским: это твое самое слабое место, иначе мы не разбогатеем!»*

### 4. Регламентный мониторинг прогресса в OpenClaw
- В `openclaw/config/cron/jobs.json` настроена периодическая проверка каждые 6 часов с 11:00 до 23:00 (11:00, 17:00, 23:00 Europe/Madrid).
- Панклоу запрашивает `/api/sessions/history?days=7`:
  * Если дневная активность ниже медианы (`todayActivities < medianDailyActivities`): отправляет владельцу напоминание.
  * Если активность на уровне или выше медианы (`todayActivities >= medianDailyActivities`): обязательно хвалит пользователя за отличный темп и усердие («Виталий, отличная работа! Твоя дневная активность сегодня на высоте...»). Ответ `NO_REPLY` не используется.
