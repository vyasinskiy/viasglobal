# Viaslangs — Сервис изучения и повторения языков

Веб-приложение для интервального повторения иностранных слов и профессиональной бизнес-лексики (английский и испанский языки).

---

## Архитектура и структура подпроекта

Проект разделен на три основных компонента:

- **`web/`** — современный веб-интерфейс на Next.js (App Router, Tailwind CSS, Material UI) для карточек повторения, списков слов, статистики и тегов.
- **`server/`** — REST API бэкенд на Node.js / Express и Prisma ORM, подключенный к базе данных PostgreSQL.
- **`client/`** — React SPA клиент (Vite / CRA).

### Схема базы данных (PostgreSQL)

- **`vy_languages`** — поддерживаемые языки (`code`: `en`, `es`).
- **`vy_words`** — карточки слов:
  - `english` — исходное слово / фраза на целевом языке (испанский или английский).
  - `russian` — перевод на русский язык.
  - `example_en` (`exampleEn`) — контекстный пример предложения на целевом языке.
  - `example_ru` (`exampleRu`) — перевод примера на русский язык.
  - `is_favorite` — признак избранного слова.
- **`vy_tags`** — тематические теги (привязаны к `language_id`).
- **`vy_word_tags`** — связь слов с тегами (многие-ко-многим).
- **`vy_answers`** — история ответов и статистика правильных/неправильных попыток.

## Тематические паки слов и теги

Все слова группируются по тематическим тегам для сфокусированного изучения (например, в контексте работы с поставщиками и оптовых закупок на Amazon Wholesale).

### Сид-скрипты в `server/prisma/`:
- **`seed-es-verbs.sql`** — топ-50 ключевых испанских глаголов для B2B общения с поставщиками.
- **`seed-tag-supplier-communication.sql`** — создание тега «Для общения с поставщиками» и привязка к нему базовых глаголов.
- **`seed-es-supplier-phrases.sql`** — 13 устойчивых выражений и терминов B2B-переписки (сроки поставки, условия оплаты, статусы заказов, согласованные условия).

## Запуск проекта

### Локальная разработка

```bash
# Установка зависимостей
npm run install:all

# Запуск бэкенда и фронтенда параллельно
npm run dev
```

### Применение SQL-сидов

Для загрузки подготовленных паков слов в базу данных:

```bash
psql -h localhost -U <user> -d <database> -f server/prisma/seed-es-supplier-phrases.sql
```
