# Правила для ИИ ассистентов (SMS Gateway)

В данном файле описаны правила работы и взаимодействия автономных AI-агентов (OpenClaw, Hermes) и разработчиков с микросервисом **SMS Gateway** (`sms-gateway`).

## 1. Назначение сервиса

- Прием входящих SMS сообщений с подключенного по USB к серверу Huawei мобильного телефона Meizu U20.
- Телефон используется как приемник SMS от банковских терминалов (CaixaBank, BBVA и др.), через которые арендаторы вносят оплату.
- Автоматический форвардинг входящих SMS владельцу в Telegram (`743866013`).
- Непрерывный мониторинг здоровья устройства (Health Check): отслеживание USB-соединения, уровня заряда батареи, статуса зарядки и активности SIM-карты.
- Предоставление REST API для чтения SMS автономным AI-ассистентом OpenClaw (`viasglobal-openclaw`).

## 2. Сетевая топология и адресация

- **Docker-контейнер**: `sms-gateway`
- **Docker-сети**: `infra_accruals-network` и `backend_default`
- **Внутренний Docker URL**: `http://sms-gateway:3040`
- **Внешний URL на хосте**: `http://localhost:3040` или `http://100.92.50.18:3040` (через Tailscale)

## 3. Спецификация REST API для OpenClaw

| Метод | Эндпоинт | Назначение |
| :--- | :--- | :--- |
| `GET` | `/health` | Комплексная проверка здоровья: статус USB, уровень батареи, оператор связи, счетчик SMS |
| `GET` | `/sms/latest` | Получение самого последнего входящего SMS (например, для проверки свежего кода подтверждения) |
| `GET` | `/sms/list` | Список SMS с пагинацией и фильтрами (`limit`, `offset`, `sender`, `search`, `since`) |
| `GET` | `/sms/:id` | Получение детальных данных конкретного SMS по числовому ID |
| `POST` | `/sms/sync` | Принудительный опрос устройства через ADB для мгновенного считывания новых сообщений |
| `POST` | `/sms/webhook` | Прием SMS через Webhook от Android-приложений (SMS Forwarder и др.) |
| `POST` | `/health/alert` | Принудительная отправка отчета о здоровье в Telegram |

### Правила обработки ответов для OpenClaw:
1. Любой эндпоинт возвращает структурированный JSON с полями `status` (`ok`, `warning` или `error`), `message` и `data`.
2. Если `GET /sms/latest` возвращает статус `404`, это означает, что новых SMS пока нет. Агент обязан корректно уведомить пользователя, а не паниковать.
3. Если арендатор сообщает в чате, что внес деньги через терминал, OpenClaw может выполнить `POST http://sms-gateway:3040/sms/sync` и затем проверить `GET http://sms-gateway:3040/sms/latest`, чтобы извлечь сумму платежа и код авторизации.

## 4. Правила работы с телефоном

- Мобильный телефон Meizu U20 подключен по USB к серверу Huawei и находится в режиме отладки по USB (ADB).
- На сервере установлен ADB (`~/.local/bin/adb`). При сбоях соединения проверять команду `adb devices -l`.
- В Telegram-уведомлениях категорически запрещено использовать длинные тире (`—`) и средние тире (`–`).
- Все комментарии в коде и автотесты пишутся строго на русском языке.
