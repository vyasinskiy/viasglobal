# Инструкции для ИИ (KUKEN / ALFA DYSER)

- **Контрагент**: ALFA DYSER, S.L. (дистрибьютор и правообладатель бренда бытовой техники и ухода KUKEN).
- **Контакты**: `alfa@alfadyser.es`, `atencionalcliente@alfadyser.com`. Портал: `https://alfadyser.es/`.
- **Прайс-лист поставщика**:
  - Файл: `contractors/kuken/viasglobal.xlsx`.
  - Формат листа: лист `Hoja1`, без строки заголовков (данные начинаются со строки 1).
  - Структура колонок:
    - Колонка A (индекс 0): системный ID строки (например, 3802).
    - Колонка B (индекс 1): артикул / референс производителя (например, `34178`).
    - Колонка C (индекс 2): наименование товара (`PLANCHA VAPOR 2200W...`).
    - Колонка D (индекс 3): чистая оптовая цена закупки **NETTO** (в евро без НДС).
    - Колонка E (индекс 4): скидка / коэффициент (0.65).
    - Колонка F (индекс 5): кратность / минимальная упаковка (1).
    - Колонка G (индекс 6): бренд (`KUKEN`).
    - Колонка H (индекс 7): **EAN** штрихкод (13 цифр, например `8425160341787`).
- **Налоговый режим**:
  - Испанский режим **Recargo de Equivalencia (R.E.)** (21% IVA + 5.2% R.E.).
  - Расчет себестоимости: `costPrice = priceNet * 1.262`.
- **Статус товаров в базе данных (сопоставление EAN)**:
  - Всего в прайс-листе: 28 позиций (11 утюгов, 15 фенов, 2 выпрямителя волос).
  - Найдено в БД: **20 позиций** (привязаны к ASIN бренда KUKEN, есть снапшоты Keepa/ProductFinder с ценами Buy Box).
  - Отсутствуют в БД: **8 позиций** (новые артикулы фенов Brushless/стенных и плоек: `8425160346584`, `8425160345464`, `8425160356354`, `8425160344368`, `8425160344559`, `8425160355746`, `8425160351809`, `8425160343477`).
