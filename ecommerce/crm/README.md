# Viasglobal E-Commerce CRM & WMS (`ecommerce/crm`)

Веб-интерфейс системы управления оптовой торговлей Amazon Wholesale, взаимоотношениями с B2B поставщиками, двухуровневым складом (СВХ / MAIN) и сквозной партионной аналитикой FIFO.

Публичный адрес через Cloudflare Tunnel: **`https://crm.viasglobal.es`**

---

## Основные разделы CRM

1. **Дашборд CRM (`/`)**:
   - Сводные KPI по всему каталогу ASIN, брендам в работе, кандидатам Wholesale, воронке поставщиков, заказам на закупку, остаткам на складах СВХ/MAIN, продажам Amazon и очередям Keepa.
   - Панель срочных уведомлений (алертов) при снижении остатка товара на оперативном складе СВХ до $\le 1$ шт.
2. **Товары в работе (`/contracted`)**:
   - Анализ товаров брендов со статусом `CONTRACTED` (Safta, Cofan, Kuken и др.).
   - Переключение между представлениями:
     * **С фильтрами (`ContractedFilteredProductsView`)**: `BSR <= 100 000`, доля Amazon $\le 50\%$, цена $\ge 10$ €.
     * **Весь каталог (`ContractedAllProductsView`)**: без ограничений по BSR, цене и присутствию Amazon.
   - Переключение налогового режима:
     * **Autónomo (Recargo de Equivalencia)**: себестоимость закупки `priceNetto * 1.262` (21% IVA + 5.2% RE), а 21% НДС на комиссии Amazon (`vatOnFees`) вычитается из чистой прибыли как прямой расход.
     * **SL (Sociedad Limitada)**: НДС на комиссии Amazon принимается к вычету и не уменьшает чистую прибыль.
   - Автоматический контроль свежести снапшота Keepa: если данные старше **48 часов**, выводится предупреждение `⚠️ УСТАРЕЛ`, а кнопка синхронизации позволяет в 1 клик отправить экстренный запрос `POST /keepa/enqueue/:asin` с приоритетом `CRITICAL (100)`.
3. **Кандидаты Wholesale (`/candidates`)**:
   - Группировка каталога **1 запись на бренд и производителя** (`CandidatesProductsView` / `WholesaleCandidatesView`).
   - Отображение количества селлеров (`sellerCount`), количества чистых ASIN (`cleanAsinCount`), причин фильтрации (`filterReasons`) и быстрое копирование списков `cleanAsins` и `eans`.
   - Поштучный поиск по представлению `AsinView` с расчетом предельной цены закупки `maxBuyPrice` под 10% целевой маржи.
4. **Поставщики и Почта IMAP (`/distributors` и `/distributors/[id]`)**:
   - Управление воронкой дистрибьюторов (`NEW` $\to$ `FORM_SUBMITTED` $\to$ `EMAIL_SENT` $\to$ `CALLED` $\to$ `ACCOUNT_OPENED` / `REJECTED`).
   - Глобальный поиск коммерческих условий (*portes, franco, pedido mínimo, tarifa*) по базе синхронизированных писем Hostinger IMAP (`DistributorEmail`, строго Read-Only).
   - Детальная карточка каждого поставщика: персональные менеджеры (`DistributorContact`), переписка, снапшоты прайс-листов (`DistributorPriceSnapshot`), заказы и накладные.
5. **Бренды, Производители и Private Label (`/brands`)**:
   - Управление статусами брендов (`UNPROCESSED`, `CONTRACTED`, `NO_EU_DISTRIBUTOR`) и заметками для генерации персонализированных *Welcome Letters*.
   - Реестр подтвержденных связок `PrivateLabelView` (`Бренд + Продавец`).
   - Справочник канонических производителей (`Manufacturer`) и привязанных к ним сырых вариаций из Keepa (`ManufacturerAlias`).
6. **Заказы и Приемка (`/orders` и `/orders/[id]`)**:
   - Учет заказов поставщикам (`PurchaseOrder`) с расчетом базы Нетто, экологического сбора RAEE (`totalEcoTasa`), налогов RE (`taxAmount`) и итоговой суммы Брутто (`totalGross`).
   - Карточка заказа со сравнением закупочных цен с текущим Buy Box Amazon, физическими замерами заводских коробок (`Д×Ш×В см`, `вес г`) и проведением приемки (`POST /orders/:id/receive`) с распределением по умолчанию **3 шт на СВХ / остальное на MAIN**.
7. **Склад СВХ / MAIN (`/inventory`)**:
   - Мониторинг остатков на оперативном складе **СВХ (`SVH`)** и основном складе **(`MAIN`)**.
   - Пополнение СВХ со склада MAIN в 1 клик по алертам (`POST /inventory/transfer`).
   - Полный журнал складских операций (`StockMovement`).
8. **Продажи и Партионный учет FIFO (`/sales`)**:
   - Регистрация продаж Amazon (`SalesOrder`) со списанием со склада СВХ.
   - Сквозная прослеживаемость партии (`Trace Batch`): наглядный отчет по любому заказу поставщика, показывающий, в какие заказы покупателей, в какие города и с какой фактической прибылью была продана каждая единица из поставки.
9. **Keepa API и Очереди (`/keepa`)**:
   - Мониторинг персистентной очереди `KeepaRequestQueue` (приоритеты `100`, `50`, `10`, `1` и резерв 10 токенов), очереди товаров `RequestProductQueue`, разрешенных категорий `KeepaAllowedCategory` и истории выгрузок `KeepaExportView`.

## Локальный запуск и разработка

```bash
cd ecommerce/crm
npm install
npm run dev
```
Приложение запустится на `http://localhost:3006` и будет проксировать запросы к `BACKEND_API_URL`.
