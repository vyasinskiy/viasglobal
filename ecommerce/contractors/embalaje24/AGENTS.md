## Стандарты расчёта совместимости коробок с плоскими курьерскими пакетами:
При проверке возможности упаковки объемной коробки $(L \times W \times H)$ в плоский курьерский пакет шириной $W_{bag}$ и длиной $L_{bag}$:
1. **Проходимость по горловине (периметр):**
   $$2 \times (W + H) \le 2 \times W_{bag} \implies W + H \le W_{bag}$$
   Для пакета $40 \times 50\text{ см}$: $W + H \le 40\text{ см}$.
2. **Полезная рабочая глубина с учетом формирования объемного дна:**
   $$L_{req} = L + \frac{1}{2} H \le L_{bag}$$
   Для пакета длиной 50 см: $L + 0.5 \times H \le 50\text{ см}$.
