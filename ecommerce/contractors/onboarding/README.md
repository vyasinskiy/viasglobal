# Онбординг поставщиков и шаблоны коммуникаций (Contractors Onboarding)

В этой директории собраны шаблоны первого контакта, квалификации, скрипты звонков, оформления писем и реквизиты компании для онбординга новых B2B-контрагентов.

## Структура директории

- [`welcome_letter/`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/welcome_letter) — Шаблон приветственного B2B письма-запроса поставщикам и дистрибьюторам, а также официальные документы компании в [`attachments/`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/welcome_letter/attachments).
- [`first_call/`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/first_call) — Скрипты звонков, чек-листы для не-носителей английского и шаблоны ответов на проверочные опросники дистрибьюторов.
- [`distributor_screening/`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/distributor_screening) — Предварительный скрининг европейских дистрибьюторов через Google NotebookLM перед отправкой писем.
- [`signature/`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/signature) — HTML-подпись и графика для электронных писем компании (совместимая со старыми почтовыми клиентами Outlook).
- [`company_profile.md`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/company_profile.md) — Официальные регистрационные и налоговые реквизиты компании, эталонный адрес для Amazon Seller Central и регламент защиты от ошибок ввода фамилии (`Iasinskii` vs `Lasinskii`) при онбординге контрагентов.
- [`duplicate_brands.json`](file:///Users/usuario/code/viasglobal/ecommerce/contractors/onboarding/duplicate_brands.json) — Дамп дубликатов брендов оптового каталога для контроля пересечений при сорсинге.
