# Правила и контекст для ИИ-агентов (E-Commerce CRM / ERP)

## Контекст подпроекта

Сервис `ecommerce` — это подсистема управления закупками, складскими остатками, каталогом продуктов, поставщиками, продажами и документами компании Viasglobal.

## Архитектура контейнеров и сетей

- **`ecommerce-backend`** (порт 3001, порт хоста 3010): NestJS REST API.
- **`ecommerce-admin`** (порт 3000, порт хоста 3020): Next.js веб-интерфейс.
- **`ecommerce-db`** (порт 5432, порт хоста 5434): PostgreSQL база данных (`ecommerce_db`).
- **Связь с агентами**: Контейнеры подключены к сети `infra_accruals-network`, благодаря чему OpenClaw и Hermes могут обращаться к бэкенду напрямую по имени `http://ecommerce-backend:3001`.

## Правила разработки и безопасности

1. **Комментарии и язык**: Все комментарии в коде пишутся строго на русском языке.
2. **База данных и Prisma**:
   - Конфигурация Prisma 7 управляется через `prisma.config.ts`.
   - Запрещено напрямую применять миграции в рабочую БД. Создание новых миграций только через `--create-only`.
   - Инициализация и сидинг выполняются через `ecommerce/backend/scripts/deploy-db.sh`.
3. **CORS и маршрутизация API**:
   - Клиент Next.js использует относительный путь `/api`.
   - Next.js проксирует запросы `/api/:path*` на `INTERNAL_API_URL` (`http://backend:3001/:path*`).
4. **Запреты**:
   - Запрещен самостоятельный деплой и коммит без подтверждения пользователя.
   - Запрещено самостоятельное удаление данных или мутация без согласования.
